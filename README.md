# Airbnb Price Predictor
Predict Airbnb listing prices with cutting-edge machine learning-achieve up to 92% accuracy and gain real-time pricing insights with a seamless, interactive experience.

Overview:

Airbnb Price Predictor is a robust, end-to-end machine learning solution designed to forecast Airbnb listing prices with high precision. The system integrates modern deployment, data management, and collaboration tools to deliver actionable insights for hosts, guests, and analysts.

Key Features:

-High Accuracy: Achieves up to 92% prediction accuracy for Airbnb prices.

-Interactive Web App: Instantly predict prices and visualize insights using a user-friendly Streamlit interface.

-Containerized Deployment: Effortlessly deploy and scale via Docker for consistent performance across environments.

-Efficient Data Management: Utilizes SQLite3 for lightweight, reliable database operations.

-Collaborative Workflow: Leverages DagsHub for version control and workflow tracking, ensuring smooth teamwork and reproducibility.

-Real-Time Analytics: Get immediate pricing recommendations and explore feature impacts live.


Tech Stack:

-Machine Learning: Advanced regression algorithms for price prediction

-Frontend: Streamlit for interactive dashboards

-Backend: Python, SQLite3 database

-Deployment: Docker containers

-Collaboration: DagsHub for version control and workflow management

Getting Started:
Clone the Repository

bash:

-git clone https://github.com/navaneeth1228/Airbnb_Price_Predictor.git

-cd Airbnb_Price_Predictor

-Build and Run with Docker

bash:

-docker build -t airbnb_price_predictor .

-docker run -p 8501:8501 airbnb_price_predictor

-Access the App

-Open your browser and go to: http://localhost:8501


Usage:

-Predict Prices: Enter listing details and get instant price predictions.

-Explore Insights: Visualize how different features (location, amenities, etc.) impact pricing.

-Collaborate: Use DagsHub integration for tracking experiments, data, and code changes.
